# V7生产材料入口 Current v1.0 正式组成文件（董事长可读版）

日期：2026-09-02  
修订日期：2026-09-11  
状态：FORMAL_GOVERNANCE_CURRENT_COMPONENT / 9月11日已确认设计文字同步，已通过总控独立核查
用途：固定完整产品生产必须看哪些材料，缺了怎么办。

## 1. 一句话

完整产品不能只靠持仓表、新闻标题或旧产品。每日新闻事件本身就是正式材料，但新闻不能只停在标题，必须进入“事实、来源、时间、影响、动作、复盘”的链条。

## 2. 账户材料

账户包括：

- IBKR；
- FUTU；
- SBI；
- Bitflyer；
- 其他账户。

口径：

- 有API就优先API；
- 无交易、无转账、无挂单、无持仓变化时，旧截图/旧快照可继承持仓数量和结构；
- 市值、资金、权重、盈亏、风险暴露优先用API、行情、汇率和账户现金/融资数据重新计算；
- 不要求董事长每天截图；
- 交易和下单必须单独授权。

## 3. 价格材料

价格包括：

- 统一价格表；
- FUTU OpenD；
- IBKR API或行情；
- 公开行情；
- 交易所或官方来源。

口径：

- 研究价格和执行价格分开；
- 延迟行情只能研究；
- 缺关键价格不能冒充完整；
- 可用其他可靠来源补价，但必须写来源和新鲜度。

## 4. 公司和监管材料

包括：

- 公司IR；
- 财报；
- EDINET；
- 债券公告；
- 产品公告；
- 监管披露。

这些材料用于判断事实，不直接替代V7动作。

## 5. 每日新闻事件和事件趋势触发材料

每日新闻事件包括：

- 宏观事件：利率、通胀、就业、央行、财政、汇率、信用风险；
- 政策事件：AI、安全、能源、半导体、数据中心、监管；
- 公司事件：财报、指引、订单、客户、产品、并购、债券、回购、管理层变化；
- 产业事件：供需、价格、库存、产能、资本开支、技术路线；
- 市场事件：价格异动、成交量、板块联动、资金流、风险偏好变化。

事件趋势触发材料包括：

- 财报日历；
- 公司IR日程；
- 监管公告；
- 债券发行材料；
- 产品发布和客户公告；
- 交易所公告；
- 权威新闻社报道；
- 行情和成交量异常；
- 板块相对强弱变化。

每条重要新闻/事件必须写清：

- 谁发布；
- 什么时间；
- 是事实、预期，还是市场传闻；
- 支撑哪个判断；
- 反向证据是什么；
- 对组合动作是减、留、等、替换、升权、降级，还是只复盘。

## 6. 权威渠道分层

第一优先级：官方和监管来源。

- 公司IR；
- 财报和电话会材料；
- SEC/EDINET/交易所公告；
- 央行、财政部、统计机构；
- 债券发行文件；
- 公司官网正式新闻稿。

第二优先级：市场数据和行情来源。

- 券商只读API；
- 交易所行情；
- 统一价格表；
- 可靠行情供应商；
- 成交量、板块和资金流数据。

第三优先级：权威媒体和专业新闻源。

- 重要财经通讯社；
- 行业专业媒体；
- 有原始来源链接的报道。

第四优先级：外部研究和观点。

- 老雷；
- 湖水；
- TXT研报；
- 观点验证数据库。

处理规则：

- 第一优先级可以作为事实锚；
- 第二优先级用于价格和市场反应；
- 第三优先级用于补充事件和市场预期；
- 第四优先级用于佐证、挑战、补盲区和PDCA；
- 任何来源都不能单独直接变成买卖动作。

## 7. 外部研究材料

包括：

- 老雷；
- 湖水；
- TXT研报；
- 观点验证数据库。

作用：

- 补充；
- 佐证；
- 唱反调；
- 暴露盲区；
- 进入PDCA。

外部观点不能直接变成买卖动作。

## 8. 历史和基线材料

包括：

- V13正式产品；
- 右栏长期标准；
- 历史PDCA；
- 历史候选；
- 失败件。

口径：

- V13是已验收基线；
- 历史候选只能查证；
- 失败件只能复盘；
- 不得把历史状态混进当前结论。

## 9. 缺材料怎么办

缺材料不能糊弄过去。

必须标成：

- 可继续：不影响核心判断；
- 降级：能做研究版，不能做金额级/完整级；
- 硬阻断：缺了就不能生产完整产品。
