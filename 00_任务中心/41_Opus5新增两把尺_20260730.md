# 尺 A · 利润指引大幅变动时的重估尺

## A1 · 何时触发（机器可判）

```
任一持仓或候选标的，公司公布的【全年净利润指引】较上次变动 ≥15%
→ 自动触发本尺重估，不等人记得
★ 变动方向不限（上调下调同样触发）
```

## A2 · 计算步骤（不需要发行股数）

```
① 取 旧净利指引 E0、新净利指引 E1、触发前收盘价 P0
② 倍数不变情形下的倒推价：P_base = P0 × (E1 ÷ E0)
③ 定折扣档（判据见 A3）：100% / 90% / 80% / 70%
④ 公允值 = P_base × 折扣
⑤ 上行空间 = 公允值 ÷ 当日价 − 1
```

**★ 为什么用倒推而不用「每股收益 × 倍数」**：
发行股数常因分割/回购变动，取错就整个错。**倒推法只用比值，天然免疫股数错误。**

## A3 · ★ 折扣档判据（这是本尺的核心，也是最容易拍脑袋的地方）

**主判据（机器可算）：利润率是否在扩张**

```
比较 净利增速 与 营收增速：

　净利增速 > 营收增速 × 1.5   → 利润率显著扩张 → 结构性成分为主 → 折扣 90%
　净利增速 ≈ 营收增速          → 纯量增        → 周期性为主   → 折扣 80%
　净利增速 < 营收增速          → 利润率在压缩   → 疑似峰值     → 折扣 70%

★ 只有同时满足下列两条，才允许给 100%：
　① 利润率显著扩张（上述第一档）
　② 且需求端有【买方自己的支出计划】作为独立证据
　　（例：主要客户公布的资本开支指引上调，而非卖方分析师预测）
```

**辅助扣减（每条 −5%，可叠加，下限 60%）**

```
· 该行业本身处于公认的周期高位
· 存在结构性竞争威胁（如新进入者取得关键技术突破）
· 上一轮同类上调后曾被下修
```

## A4 · 必须同时输出的（防止只给一个数）

```
① 四档折扣对应的四个公允值全部列出，不许只给采用的那一档
② 明确标注「折扣档是判断，不是计算」
③ 失效条件必须包含主判据的反面：
　「若下季净利增速回落至营收增速以下，则折扣档须下调」
```

# 尺 B · 控股型／净资产驱动标的估值尺

## B1 · 适用对象（机器可判）

```
满足任一即适用：
· 主要资产为对其他公司的持股，本身无实质经营损益
· 公司自身以「净资产价值(NAV)」而非营业利润作为主要价值指标披露
· 现有估值引擎对其产出 normal_eps = null 或双口径差异 >30%
```

## B2 · ★ 三层法（取代「在多个 NAV 口径里挑一个」）

```
第一层 · 硬（可独立复核）
　= Σ[已上市子公司/持股 的市价 × 持股比例] − 以这些股票为抵押的负债
　÷ 发行股数 = 每股可验证下限
　★ 这一层只用公开市价与公司披露的负债，无争议

第二层 · 软（只给区间，禁止给单值）
　未上市资产（未上市持股、基金份额、自建资产）
　★ 给区间上下限即可。★禁止取中值当作单一答案

第三层 · 判断（唯一能指导动作的一层）
　当日价 ÷ 第一层每股下限 = R
　　R < 1.0        → ★未上市资产等于免费送 → 强买入区
　　1.0 ≤ R < 1+第二层下限占比 → 合理偏低
　　R > 1+第二层上限占比       → 贵
```

## B3 · ★ 为什么这样定（方法论理由，写进尺以免以后被推翻）

```
「这家控股公司值多少钱」——没有唯一答案，因为未上市资产估值本身无唯一答案。
「现价有没有跌破只算已上市部分的价值」——有唯一答案。

★ 尺的作用是把无解的问题，换成一个可证伪的问题。
★ 在两个都合理的 NAV 口径里挑一个，是假装解决了问题 —— 本尺明确禁止这种做法。
```

## B4 · 必须输出的（缺一即不合格）

```
① 第一层每股下限的完整算式（含每一项持股比例与市价来源）
② 第二层的区间上下限，及构成明细
③ R 值与所处区间
④ ★若第一层所需数据缺失 → 标「待取数」并列出缺哪几项，
　 ★不许因此退回到「在两个口径里挑一个」
```
