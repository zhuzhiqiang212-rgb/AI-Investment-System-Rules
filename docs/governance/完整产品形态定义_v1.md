## 四 · 左右栏结构与「咬合」的正式定义（裁定第三节三）

### 4.1 结构（出处：《生产流程规范》§2）
> 逐字：「**右栏＝6 块"尺"底子**（①世界观 ②国家战略地图 ③资金流动机制 ④板块地图 ⑤过滤五关 ⑥持仓档案），慢变、很少改；**改尺＝改右栏，走董事长**。
> **左栏＝判断层**，每日现算：拿右栏对应那把尺，去量今日真数据、出读数与决策。**左右编号必须一一对应、咬合**；左栏结论不得脱离右栏尺。」

### 4.2 ★咬合的正式判据（裁定明确：「左右栏存在且字节数>0 只能证明有容器，不能证明已经咬合」）

1. 每个左栏结论必须带 `conclusion_id`
2. 每个结论必须引用**至少一个**右栏 `evidence_id` 或 `rule_id`
3. 右栏证据必须登记**来源、日期、SHA 或 URL**
4. 检查器验证**引用真实存在**（不是写了个 ID 就算）
5. 人工再判断**证据是否足以支持该结论**
6. 存在**左栏孤立结论**（无引用）时，必须列入合规报告

> ★★★董事长补充的关键判断（2026-08-08）：
> 「**这套机制真正有效的核心，不是"有一张清单"，而是左栏每个结论都必须引用右栏证据ID。**否则即使左右栏都有很多文字，仍可能是两张互不相关的皮。」
> **本条列为本定义的最高优先级要求。**

## 六 · 四个必备区块的内容要求（逐字提取）

### 6.1 板块趋势（§3.2）
- 说清**现在什么热、接下来什么趋势**
- 每条趋势带**过去 → 现在 → 未来**，并写明**时间窗多久**
- 配图（热度/趋势条）

### 6.2 五关漏斗（§3.3·每只持仓＋候选都走完）
- ①硬性/方向 ②软性/位置 ③估值 ④护城河 ⑤深研——**每关都要真结论**
- **任一关「待补/待填」即断点即不合格**（可暂标「初判」，但不得当定论、不许拿「待补」冒充结论）
- **加密资产口径定死**：BTC/ETH 是资产、不做企业估值与护城河，只受「加密≤12%纪律＋币价」管；用词统一为「资产口径」，**不制造"待补"假断点**

### 6.3 《交易动作区》· 决策卡五格（§3.4·每张卡五格缺一格＝没做完）
| 格 | 要求（逐字） |
|---|---|
| ① 为什么 | 真理由，含它和你实际持仓的关系 |
| ② 怎么动 | 守/减/加/换，讲机制（分批、减到限内不清仓…） |
| ③ 什么价 | 来自估值——买点＝合理区下沿、止盈线；**别在便宜区贱卖赢家** |
| ④ 多少量 | 占比目标＋**具体股数**，且不撑破 AI/单一/加密上限 |
| ⑤ 钱从哪来/影响 | 减能腾出多少、换掉的是谁 |

- 先看**目标 vs 实际**（集中度 5 线·带图）
- 动作要摆**几条路＋事实**，董事长拍板

### 6.4 机会层（§3.5·常备换仓清单）
- **不天天换**，常年盯：**什么价买、什么价卖、什么条件才换掉现有哪只持仓**
- 每个候选写清：什么价买＋**换谁**＋**换的条件**（候选护城河更宽＋回到便宜位＋被换的那只涨回止盈＋换完总敞口不升，**全满足才提示"换"**）＋**现在状态**
- ★**不许写"今天没有机会标的"**；AI 已超配时，新 AI 候选只能"换"不能"加"
- 每个候选自动带「属哪个承接节点＋当日哪条证据」

### 6.5 《复盘记分卡》（§3.6）
- **对着目标看差距**：比「目标配置 vs 实际」「昨天的判断/动作 vs 后来结果」
- **各环齐**：力度/得分/把握/理由/下一步
- 5 迭代动作：①毕业候选 ②回炉 ③调力度 ④沉淀规则 ⑤迭代清单——**都只建议**
- **回校世界观**：把当日各环证据绕回三支柱做支持/证伪

### 6.6 呈现（§3.7 · ★已按 GPT V7 C-6 裁定修正）
- **页首先给动作摘要**：方向短句＋3–5 条动作（守谁/别加谁/该减谁）＋底气
- ★★★**「不用滚就看完」作为强制篇幅限制【已失效】**（GPT V7 2026-08-08 第四节裁定）。
  ~~不用滚就看完~~ → **不得以「不用滚看完」为强制篇幅限制；第一层必须答透**
- **紧接完整第一层**（十项必答·见 §6.3-2），**不得为缩短篇幅删掉重要决策信息**
- 深层研究允许折叠，**但不得不生产**
