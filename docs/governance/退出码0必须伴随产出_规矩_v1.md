# 退出码0 必须伴随产出（v1·轮336）

> 立于 2026-08-09（轮336·董事长令）。★位置待董事长定（暂放 docs/governance/）。

## 一、规矩（一句话）

**任何 build / pipeline 脚本：退出码 0 却【没有任何"我做了什么"的结构化产出】（没写产物文件、也没打任何一步日志/摘要）→ 必须强制改成非 0，并在台账记「未生产·原因」。**

## 二、理由（董事长原话·照抄）

> **「报『没做到』不扣分，假报『做到了』是信任击穿。」退出码 0 就是机器版的『我做到了』。**

- 退出码 0 = 机器在说"我做到了"。
- 若它退 0 却什么都没产出（提前 return、异常被吞、子进程静默失败），就是**机器版的假报做到了**——比报错更危险，因为**没人会去查一个"成功"的步骤**。
- 轮334：dry-run 退出 0 却零输出（当时以为静默失败）；轮335 查清那次是 stdout 块缓冲（已修行缓冲）。★但**"退出0却零产出"这个形态本身**要被防住——换个原因还会再犯。

## 三、落地（已实现）

- **乙1 daily_auto_produce.py**：退出口守卫——①异常抛顶→不吞·退 3；②`_STEPS_RAN==0`（没跑任何一步）却返回 0 → 强制退 3 + `_emergency_ledger` 记 `FAILED_NO_OUTPUT`。
- **乙2 通用闸 `scripts/exit_guard.py`**：`guarded(main, produced=…, steps_ran=…, on_fail=…)`——其它 build/pipeline 脚本可包裹自己的 main：返回 0 却 `produced()=False` 或 `steps_ran()==0` → 退非 0。★各脚本按需逐步接（daily_auto_produce 已内建同款逻辑）。
- **乙4 自测**：模拟"某步第一行 return"（main 零步骤返回 0）→ 守卫触发·退出码=3·台账记 `FAILED_NO_OUTPUT`·原因含"零步骤"。已过。

## 四、判据（结构化·守 §5.4）

- **不靠自由文本**：判据 = `steps_ran()==0`（计数）或 `produced()=False`（产物文件是否存在）——都是结构化信号，不读日志关键词。
- "产出"的定义：写了产物文件（json/html/…）**或**跑了至少一步（`_STEPS_RAN>0`）。二者皆无 = 零产出。

## 五、同族规矩

与《判断层不写死机器数_token规矩_v1》《数据层文案不许夹带HTML标签（CLAUDE.md §5.5）》同族：
**机器不许悄悄地"看起来成功"——要么真产出、要么如实报未做到，绝不假报做到了。**
