V7正式生产SOP v1.0

本目录实现“每天怎样生产”的规则与校验结构，不是业务蓝图，也不是每日产品。

核心边界

  • 结构继承，事实刷新；机制复用，结论重算。
  • EDINET定位为日本公司法定一手披露源，只做增量检查，不重复下载未变化历史文件。
  • 老雷、湖水及其他TXT按SHA和消费状态增量读取，不迁移或重扫全部历史资料。
  • V13作为研究基座，动态层可以更新事实与结论，但不能覆盖V13身份。
  • 硬阻断停止生产；软缺失进入降级模式并降低相应判断把握度。
