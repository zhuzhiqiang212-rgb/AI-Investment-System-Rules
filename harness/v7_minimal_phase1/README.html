V7最小 Harness · 第一阶段

这是一套防跑偏控制壳，不是完整生产系统。它只管理一项正式任务的身份、范围、阶段、权限、文件指纹、验收层级和恢复位置。

组成

  • RUN_CONTROL.json：本最小 Harness 当前任务的唯一机器状态。
  • run_control.schema.json：最小字段结构。
  • validate_run_control.py：只读检查，不修改、不修复、不推进状态。
  • tests/：十项边界测试和测试报告生成器。

只读校验

python harness/v7_minimal_phase1/validate_run_control.py --control harness/v7_minimal_phase1/RUN_CONTROL.json --project-root .

校验通过只表示控制关系一致，不代表独立终验、GPT业务验收、董事长批准或Release授权。

本阶段不管理

不管理产品生产、宏观抓取、财报研究、新闻抓取、PDCA回灌、账户同步、券商交易、订单、日报、Release流水线、数据库、网页界面或多执行器调度。
